# Superseded public prototype checks

The owner explicitly requested staff sign-in and server-side role permissions, and chose sample accounts with no real patient information. These earlier tests required anonymous requests, free switching between EMS/hospital roles and arbitrary facility selection. That contract is replaced by S-042–S-052, including actual Piezas-managed sessions, pending staff approval, cross-role denial, confirmation, accountability and deletion checks. The old tests and SPEC are retained unchanged for history; they are not silently loosened or marked skipped.
