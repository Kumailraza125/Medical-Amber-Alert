# Medical-Amber-Alert
A alert to all hospitals in the area requesting certain resources

Try the demo workflow:
1. You start as Cedar Valley Community Hospital — click New request, pick MRI, keep the default 100 km, send.
2. Switch the hospital dropdown to Maplewood Regional → open Incoming tab → open the request → Offer availability.
3. Switch back to Cedar Valley → open the request → Accept → Mark completed.
